# SITL_LOCKSTEP master build. Convert to a boot-ready EEPROM image with:
#
#   obj/multi/betaflight_SITL_LOCKSTEP_MULTI \
#       --cli-dump tools/lockstep_instancer/configs/air75/air75_wisp_sim.txt \
#       --eeprom obj/configs/air75_wisp.bin
#
# This is the same translation scheme as air75_sim.txt (see its header for the
# full rationale); only the flight tune differs. The raw 4.5.0 "dump all"
# cannot be fed to the master converter directly: it rejects the renamed 4.5
# settings (serialrx_provider, dshot_*, min_throttle, beeper_*, d_min_*, ...)
# and would still apply motor_pwm_protocol DSHOT300, which trips the
# MOTOR_PROTO arming block. So we start from `defaults nosave` and re-apply
# only the master-valid, flight-relevant deltas.
#
# Translations / drops vs the vendor wisp dump:
#   d_min_roll 30 / d_min_pitch 34   -> d_roll 30 / d_pitch 34  (4.6 D/Dmax
#       rework renamed d_min -> d; the old static D 40/46 -> d_max_roll/pitch)
#   dshot_idle_value 550             -> motor_idle 550 (master unified idle)
#   motor_pwm_protocol DSHOT300      -> dropped (SITL has no DSHOT transport;
#       trips MOTOR_PROTO; idle floor carried by motor_idle)
#   dshot_bidir / dshot_bitbang      -> dropped (no DSHOT telemetry in sim;
#       same KNOWN GAP as air75_sim.txt: real quad's RPM filter is absent)
#   feature RX_SERIAL / serialrx CRSF-> dropped (no serial RX in sim -> RXLOSS)
#   feature TELEMETRY / vtx / gps    -> dropped (no such hardware in SITL)
#   acc_calibration                  -> dropped (sim accel is already perfect)
#   aux 0 ARM remapped onto AUX1 hi  -> matches the harness RC injection so the
#       arm switch actually clears (vendor mapped ARM to AUX3, which the sim
#       harness never drives -> ARM_SWITCH lockout)
#
# The wisp profile-0 PIDs are stock Betaflight 4.5 defaults; the only real
# deltas from a default tune are the dynamic-notch config and the rates.
# OSD block is kept (made visible in profile 1 so the sim grid renders).
